## 3. Root Cause Từng Lỗi & Chi tiết Thay đổi (FIX A/B/C)

### 3.1. FIX A — `CameraConnectionNoteValidator` & `cameraValidation.ts` Bỏ Lọt Credential
- **Root cause:** `BARE_USERINFO_PATTERN` ở bản G5.5.2a dùng negative lookahead `(?:^|\s)(?!e?mail:)[^\s:@/]+:[^\s@/]*@[^\s/:]+`, tạo lỗ hổng cho phép `email:secret@cam.local` và `mail:secret@cam.local` đi qua; đồng thời chỉ neo đầu chuỗi hoặc `\s` nên bỏ sót trường hợp dính dấu câu như `Label:(admin:secret@cam.local)`.
- **Thay đổi thực hiện:**
  - Backend `CameraConnectionNoteValidator.java`: đổi `BARE_USERINFO_PATTERN` thành `(?i)(?:^|[\\s(\\[{\"'<,;:=])[^\\s:@/(\\[{\"'<,;]+:[^\\s@/]*@[^\\s/:()\\[\\]{}\"'<>,;]+`.
  - Frontend `cameraValidation.ts`: đồng bộ regex JS `/(?:^|[\s([{"'<,;:=])[^\s:@/([{"'<,;]+:[^\s@/]*@[^\s/:()[\]{}"'<>,;]+/i`.
  - Không echo raw secret; luôn ném lỗi cố định `VALIDATION_ERROR`, field `connectionNote`.
  - Vẫn chấp nhận các email bình thường không đi kèm credential trước `:` như `support@example.com` và `Email: support@example.com`.

### 3.2. FIX B — Sai Lệch Độ dài Cột `Camera.status` vs `V1__initial_schema.sql`
- **Root cause:** `V1__initial_schema.sql` định nghĩa `cameras.status VARCHAR(20) NOT NULL DEFAULT 'OFFLINE' CHECK (status IN ('ONLINE', 'OFFLINE', 'ERROR'))`, nhưng entity `Camera.java` lại khai báo `@Column(name = "status", nullable = false, length = 50)`.
- **Thay đổi thực hiện:** Sửa `Camera.java` thành `length = 20`; bổ sung kiểm tra bảng `cameras` vào `DatabaseSchemaIntegrationTest.java` (H2 `coreJpaTables`, PostgreSQL `information_schema.columns` kiểm tra `name = 200` và `status = 20`, `is_nullable = 'NO'`, kèm JPA `@Column` reflection test chạy trên cả hai profile).

### 3.3. FIX C — Sai Cạnh Phụ thuộc `SEC --> C1` Trong Mermaid Roadmap
- **Root cause:** Mục 15 của `docs/roadmap/g5.5-technical-readiness-and-implementation-roadmap.md` vẽ cạnh `SEC --> C1` làm hiểu nhầm Camera Metadata CRUD (`C1`) phụ thuộc vào `MediaUrlValidator + Rate Limit` (`SEC`) hoặc khiến người đọc tưởng `SEC` đã hoàn thành cùng `C1`; đồng thời nhãn node `C1` vẫn ghi `4 API Backlog`.
- **Thay đổi thực hiện:** Gỡ cạnh `SEC --> C1`, giữ `SEC --> ST` và các cạnh đúng khác; đổi nhãn `C1` sang `G5.5.2a: Camera Metadata CRUD (Bảng cameras V1 + 4 API đã triển khai)`; bổ sung giải thích rõ `CameraConnectionNoteValidator` là validator riêng cho ghi chú camera, **không** thay thế `MediaUrlValidator`; giữ nguyên `SEC`, `G5.5.2b` (`Proposed but not implemented`), `Phase C2 (Live Stream)` và `G5.5.3–G5.5.6` ở trạng thái Backlog.
